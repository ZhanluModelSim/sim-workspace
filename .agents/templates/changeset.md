# ChangeSet 记录模板

适用范围与唯一记录位置见[轻量 RSI 工作流](../workflows/lightweight-rsi.md)。复制到选定记录后填写；简单任务可合并字段，不适用项说明原因。这不是机器 Schema 或发布锁文件。

## 目标与范围

- ID、状态、牵头方与唯一记录链接：
- 问题、最小复现与原始证据：
- 改进假设、预期收益及适用范围：
- 允许修改的仓库/接口，排除项与未决问题：
- 不变量、接受/放弃/停止条件；多轮试验预算（如适用）：

## 对照与组合

- 评估案例、命令、配置、判定方式及其版本：
- 基线组合：组件 commit、dirty/补丁或制品引用、环境和实际导入位置：
- 候选组合：同上，说明变化及无法固定的条件：
- 数据/硬件来源及证据类型（Meta、synthetic、真实预测、设备测量）：
- 流程改进的代表任务、观察方法及尚未验证的效果假设：

## 尝试与结论

| 候选/尝试 | 变更与证据引用 | 基线与候选对比 | 通过/失败/跳过/未运行及原因 | 决定与理由 |
| --- | --- | --- | --- | --- |
| 待填写 | | | | |

- 独立 reviewer、意见与处理结果；未覆盖风险：
- 评估口径如有变化，其原因、审查依据及与旧结果的可比性：
- 最终决定（接受/放弃/待验证）；已提交不等于已验证：

## 交付与沉淀

- 各仓提交/PR、依赖顺序、最终组合验证证据：
- 失败时恢复的已知组合、需撤回的提交/制品及兼容过渡限制：
- 已获授权的提交/发布范围及实际执行状态：
- 更新的回归、工具、领域文档或公共流程链接：
- 后续待办及唯一跟踪位置；证据存放与接手方式：
