# 公共 agent 资料

本目录由工作区管理仓维护，供跨仓协作复用。规则入口是根 [AGENTS.md](../AGENTS.md)，文档与协作规范见 [workspace-conventions.md](../docs/workspace-conventions.md)。

## 放置范围

- 可跨仓复用的操作指南和文档模板。
- 经明确任务创建的公共技能；每个技能在独立目录中维护适用范围、步骤与依赖。
- 仅适用于某业务仓库的规则和技能仍归该业务仓库，不提升到公共层。

## 推荐工作流

[多仓协作推荐工作流](workflows/multi-agent-development.md) 是后续开发的默认推荐方式：主 agent 负责需求讨论与最终验收，按需委派范围明确的独立任务。当前需求讨论由主 agent 直接完成，不预设每仓固定一个子 agent。

根 AGENTS.md 已显式引用此工作流。它是协作指南，不是已安装的自动化技能；不预建技能或自动安装脚本。不同工具的发现与加载方式可能不同，不假定目录内所有内容自动生效。

## 维护要求

优先引用已有规范，避免复制正文。共享内容使用相对路径或可配置参数，不包含凭据、个人环境和本机运行状态。个人临时内容可放入被忽略的 `local/`，不要提交。

新增或修改公共流程时，说明适用任务、输入输出及相关仓库；检查链接，并核对是否与根 AGENTS.md 或业务规则冲突。

## Python 开发规范

[Python 开发与验收规范](standards/python-development.md) 统一新仓的格式、类型、接口、测试与交付习惯；已有训练仓保留上游工具链。各业务仓 AGENTS.md 提供本仓适用范围及公共规范链接。
