# 大模型负载仿真工作区

SIMPlatform 将训练／推理负载捕获、算子性能预测与仿真串起来，输出时延、吞吐、静态显存预算、算子统计和时间线。支持单任务和参数扫描批量执行。

## 使用 SIMPlatform

从 [SIMPlatform 用户 Wiki](https://github.com/ZhanluModelSim/sim-workspace/wiki/Home) 开始。可以直接把 Wiki 首页链接发给 AI，让它帮你安装或更新发布镜像、准备配套技能并运行最小示例。使用镜像无需克隆源码。
