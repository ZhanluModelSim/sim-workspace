# 文档索引

按任务选择入口，以下不是顺序阅读清单。使用参数、示例、接口和测试方法由对应业务仓维护。

| 当前任务 | 需要阅读 |
| --- | --- |
| 首次启动、得到 demo 结果 | [工作区首页](../README.md) |
| 修改配置、批量运行、推理或阅读结果 | [首页「接下来做什么」](../README.md#接下来做什么)中的对应平台指南 |
| 克隆源码与准备开发 | [开发指南](development.md) |
| AI 修改代码或文档 | [AGENTS.md](../AGENTS.md)与目标仓适用规则，再按任务选专题 |
| 调整跨仓职责或接口 | [跨仓职责与协作边界](backend-requirements.md)中的相关章节 |
| 查询未完成能力或待确认决策 | [跨仓待办](roadmap.md) |
| 整理文档或调整协作约定 | [公共协作与文档规范](workspace-conventions.md) |
| 需要公共开发流程、模板或 Python 规范 | [公共 agent 资料](../.agents/README.md)中的对应条目 |

不要递归展开所有链接作为任务前置阅读。遇到接口、依赖或职责不明，再沿相关链接补充上下文。`bootstrap/` 是历史资料，仅在明确追溯时读取，不作为当前实现依据。
